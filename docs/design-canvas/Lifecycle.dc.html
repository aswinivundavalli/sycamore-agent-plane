Exactly-once transitions. Each move is UPDATE … WHERE state IN (…). Concurrent requests from duplicate clicks, multiple sessions or a recovering scheduler resolve to a single winner.
Cancellation. Any queued, starting, running or testing run can be stopped. Its entire process group is terminated, and its worktree and branch are released.
